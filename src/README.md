# 自研代码

这里存放自己的算子实现、优化算法、代码生成器和共享框架，按实际功能建立子目录。当前只建立目录约定，具体语言和模块结构随开发任务确定。

- 可复用的实现与工具放在 `src/`。
- 基准实现、输入用例、参考模型、验证与测量入口放在 [bench/](../bench/README.md)。候选实现由 benchmark 调用，避免复制出两份源码。
- 单次任务的说明、参数和复现配置放在 [tasks/](../tasks/README.md)。
- 生成的 RTL、网表、日志、波形和指标放在 [experiments/](../experiments/README.md) 对应 Run 中；需要长期维护的实现源文件才放入这里。

共享接口和评测相关代码的修改按[代码审查约定](../docs/code-review.md)核查。
